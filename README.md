# Baden Haus — лендинг

Одностраничный сайт гостевого дома с баней и чаном **Baden Haus** (Иркутск, п. Изумрудный).

## Структура

```
index.html          — страница (10 блоков)
css/style.css       — стили
js/main.js          — бургер-меню, калькулятор, слайдер отзывов, галерея, карта
img/                — оптимизированные изображения (WebP + JPG-фолбэк, 800/1600 px)
favicon.ico, site.webmanifest
robots.txt, sitemap.xml   — SEO
llms.txt            — GEO (описание для AI-поисковиков)
humans.txt, .htaccess
```

## Блоки

1. Шапка + первый экран (факты: 20 мин, 8 мест, 42°)
2. Дом — удобства
3. Банный ритуал: 90° / 40° / −20°
4. Мангальная зона
5. Галерея с лайтбоксом
6. Цены + интерактивный калькулятор (заявка в Telegram)
7. Условия, правила, FAQ
8. Отзывы — слайдер со свайпом
9. Призыв к бронированию
10. Контакты + Яндекс Карта (ленивая загрузка)

## Перед публикацией

- Заменить домен `https://badenhaus38.ru/` на реальный (index.html, robots.txt, sitemap.xml, llms.txt).
- **Отзывы в блоке 7 — демонстрационные**, заменить на реальные отзывы гостей.
- Уточнить у владельца точный адрес / координаты для карты.

Совместимость: Chrome, Safari (iOS 12+), Firefox, Edge, Samsung Internet, Яндекс Браузер. Учтены safe-area для iPhone.
